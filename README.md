# adobe-experience-platform

## Adobe Experience Platform

Adobe Experience Platform (AEP) is a cloud-based platform that helps businesses collect, manage, and analyze customer data to deliver personalized experiences across different channels. It provides a unified view of the customer, enabling businesses to understand customer behavior, preferences, and interactions, and use this information to deliver relevant and timely experiences.
